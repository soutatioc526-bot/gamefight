# Gamefight 割草肉鸽 Demo

一个零依赖 HTML5 Canvas 原型，方向调整为碎片时间可反复打开玩的肉鸽割草循环。

## 运行

直接打开 `index.html`，或在项目目录启动本地静态服务：

```powershell
python -m http.server 5173 --bind 0.0.0.0
```

本机访问：

```text
http://127.0.0.1:5173/
```

## 当前玩法

- 主界面只保留“开始冒险”。
- 如果有上一次选择的初始武器，会直接进入战斗。
- 如果没有记录，会进入初始武器选择。
- 当前版本只有一个统一主角，三张开局卡是初始武器，不是角色。
- 敌人死亡后掉落蓝色经验晶体，靠近拾取后才会增长经验条。
- 经验升级只出现人物属性卡，不再混入武器、遗物或神明祝福。
- 第 5 层清怪后进入安全地图寻找神龛，神龛是有代价的风险交易。
- 第 9 层 Boss 掉落圣遗物，拾取后从 3 个神明祝福中选择 1 个。
- 第 10 层是安全铁匠地图，铁匠只提供当前武器附魔。
- 每次进入下一层前都会弹出确认窗口，点击确认后再推进。
- 战斗地图按楼层切换：1-5、6-10、11-15、16-20 各使用一张地图纹理。
- 金币用于普通升级重掷、Boss 祝福重掷、铁匠刷新/强化和神龛交易。

## 初始武器

- `裂隙短刃`：近身赌命流，短冷却扇形刀光。
- `秘银飞弹`：奥术弹幕流，自动锁定敌人。
- `回旋飞镖`：拉扯收割流，飞出和返回都能造成伤害。

## 操作

- 移动端：按住屏幕任意位置拖动，会在触点位置显示低透明虚拟摇杆。
- 桌面端：`WASD` 或方向键移动。
- 武器自动攻击，不需要手动点怪。
- 空格：标题页开始冒险，战斗中打开/关闭暂停菜单。

## 当前循环

```text
开始冒险
  -> 自动使用上次武器或选择初始武器
  -> 进入战斗
  -> 击败敌人掉落经验晶体和金币
  -> 拾取经验后触发人物升级三选一，可用金币刷新一次
  -> 进入下一层前先确认
  -> 第 5 层清怪后进入安全神龛地图
  -> 第 9 层 Boss 掉落圣遗物，选择神明祝福后普通局结算
  -> 继续深入进入第 10 层安全铁匠地图，获得当前武器附魔
  -> 死亡后可立即再来一局
```

## 数据配置

主要数据集中在 `src/data/gameData.js`：

- `playerUpgrades`：经验升级的人物属性卡。
- `weaponEnchantments`：铁匠附魔池。
- `divineBlessings`：Boss 圣遗物祝福池。
- `shrineEvents`：神龛风险交易。
- `economy`：金币收入与重掷、刷新、强化价格。
- `floorPlan`：第 5 / 10 / 15 等安全事件层节奏。

## 地图资源

## 存档字段

使用 `localStorage` 保存轻量长期记录：

- `lastStartingWeapon`
- `unlockedAchievements`
- `highestFloor`
- `clearedNormalMode`
- `unlockedDeepChallenge`
- `highestKills`
- `bestSynergy`
- 设置项预留
