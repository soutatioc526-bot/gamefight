# 无尽裂隙

一个零依赖 HTML5 Canvas 原型，当前方向是 10 层一循环的短局动作构筑。

## 运行

直接打开 `index.html`，或在项目目录启动本地静态服务：

```powershell
python -m http.server 5173 --bind 0.0.0.0
```

本机访问：

```text
http://127.0.0.1:5173/
```

## 当前玩法

- 每次进入空间裂隙前都会重新选择初始武器。
- 裂隙祝福不再由拾取成长资源触发；每层怪潮清空后出现 3 张卡牌，选择 1 张，可花金币刷新。
- 第 3 层固定出现沉默神龛，提供爱心恢复、献祭、交易或离开等裂隙交易。
- 第 5 层出现裂隙追猎者，使用 Boss 登场动画；打到半血后会逃入裂隙深处，并提示继续追击。
- 第 8 层出现流浪铁匠，可为当前武器附魔，且有概率出现武器升阶选项。
- 第 9 层出现副首领，用于验证刚获得的附魔是否改变打法。
- 第 10 层只出现阶段 Boss。击败后会在场内持续 3 秒喷出大量金币，并掉落发光武器回声。
- Boss 武器回声需要在场内拾取，拾取后才会显示升阶当前武器或概率解锁新武器的结果。
- 首次击败第 10 层 Boss 时，若仍有未解锁武器，会优先出现一把新武器。

## 初始武器

- 默认解锁：`拳套`、`太刀`、`法杖`。
- Boss 回声可解锁：`飞镖`、`绣花针`。
- 武器每局从Ⅰ阶开始，最高Ⅴ阶；已解锁武器会写入存档，不随重开本局丢失。

## 操作

- 移动端：按住屏幕任意位置拖动，会在触点位置显示低透明虚拟摇杆。
- 桌面端：`WASD` 或方向键移动。
- 武器自动攻击，不需要手动点怪。
- 空格：标题页开始冒险，战斗中打开或关闭暂停菜单。

## 当前循环

```text
开始冒险
  -> 选择已解锁初始武器
  -> 进入本层
  -> 击败敌人获得金币
  -> 怪潮清空后选择裂隙祝福三选一
  -> 第 3 层沉默神龛
  -> 第 5 层裂隙追猎者半血逃跑
  -> 第 8 层流浪铁匠附魔
  -> 第 9 层副首领
  -> 第 10 层阶段 Boss
  -> 拾取场内武器回声
  -> 进入下一轮 10 层循环
```

## 数据配置

主要数据集中在 `src/data/gameData.js`：

- `playerUpgrades`：裂隙祝福池。
- `weaponEnchantments`：流浪铁匠附魔池，含拳套和绣花针专属附魔。
- `shrineEvents`：沉默神龛的裂隙交易。
- `economy`：金币收入与刷新、附魔价格。
- `floorPlan`：10 层循环结构。
- `weaponConfigs`：五把武器的定位、关键词、阶级技能、UI 描述和基础数值。
- `bossWeaponDrop`：Boss 武器回声候选池和残响转化规则。

法杖魔法弹使用 `effect_magic_missile_sheet.png` 的 7 帧反馈素材：

- 前 3 帧：发出、飞行、拖尾。
- 后 4 帧：击中、爆开、消散。

打击反馈包含伤害数字、combo 文本、敌人红闪、击退、受击灰尘、爆点对象池、近战镜头轻晃、短帧冻结和振动反馈。

## 美术制作数值

基础画布与场景：

- 逻辑视口：`360 x 640`，画面按该比例缩放。
- 世界尺寸：`980 x 1320`，安全边界 `x 48-932`、`y 72-1260`。
- 玩家判定半径：`15`，基础移速 `170`，虚拟摇杆半径 `48`。
- 主角四面图：每张图按 4 行读取，行顺序为前、右、后、左；游戏内绘制尺寸 `76 x 116`，中心点在角色脚底上方约 `62px`。
- 备用角色序列帧：单帧 `128 x 128`，游戏内绘制 `70 x 70`。

攻击与特效：

- 拳套：基础伤害 `18`，冷却 `0.44s`，范围 `46`；升阶范围依次约 `46/48/58/78/92`。
- 太刀：基础伤害 `24`，冷却 `0.66s`，范围 `64`；升阶范围 `64/60/112/116/128`。
- 法杖：基础伤害 `34`，冷却 `0.86s`，索敌范围 `230`；3 级魔阵半径 `68`，4 级爆裂 `84`，5 级光束 `280`。
- 飞镖：基础伤害 `21`，冷却 `0.72s`，范围 `238`；升阶范围 `238/246/252/266/280`。
- 绣花针：基础伤害 `11`，冷却 `0.34s`，范围 `250`；5 级针网半径 `76`。
- 太刀刀光素材：`128 x 128`，`6` 帧，`18fps`；游戏内绘制尺寸约 `max(88, 攻击半径 x 2.15)`。
- 法杖飞弹素材：`256 x 256`，`7` 帧，`24fps`；飞行帧绘制 `46/60/78`，命中帧绘制 `86-120`。
- 飞镖拖尾素材：`128 x 128`，`7` 帧，`20fps`；游戏内绘制约 `72 x 72`。

受击反馈：

- 普通命中：敌人冻结 `40-60ms`，震动 `8ms`，镜头抖动约 `1.2`。
- 重击/爆发：敌人冻结 `80-120ms`，震动 `18ms`，镜头抖动约 `3.4`。
- 近战命中：镜头抖动约 `2.2`。
- Boss 命中反馈倍率：`0.34`；精英/副首领倍率：`0.72`。
- 击退基础值：太刀 `108`，拳套 `102`，飞镖 `58`，绣花针 `28`，通用 `38`；Boss 击退倍率 `0.25`，精英/副首领 `0.45`。
- 受击爆点：太刀半径 `24`、生命 `0.24s`；其他半径 `18`、生命 `0.18s`。
- 受击灰尘：每次 `2` 个，半径 `7-13`，生命 `0.24-0.38s`。

Boss 预警与弹幕：

- 突进预警 `0.55s`，突进速度 `620`，停止后 AOE 预警 `2s`，AOE 半径 `118`。
- 360 度弹幕持续 `3s`，弹幕速度 `190`，半径 `6`，每 `0.12s` 发射一组。
- 瞬移能量波蓄力 `3s`，宽度 `112`，长度 `1280`，发射 `1.35s`，伤害检测间隔 `0.24s`。
- 锁定玩家 `3s` 后向最后锁定位置发射 `10` 枚飞弹。
- 随机巨石机制：在四个远处角落召唤巨石，巨石依次造成超大半屏范围爆炸。
- 连续直线冲刺：Boss 随机选取全屏直线范围连续冲刺 10 次，每次会在最终停留位置发起下一次预警。
- 半血机制：Boss 分裂 `10` 个小怪并进入无敌状态；每 `2s` 在全屏随机位置生成 `50` 个 AOE，小怪全灭后解除无敌。
- 终局机制：Boss 剩余 `10%` 血量时必定触发全屏 AOE，Boss 脚下约 `98px` 半径为镂空安全区，`3s` 后安全范围外受到高额伤害。
- 第 5 层裂隙追猎者不包含半血后的分裂、全屏 AOE 和终局机制；半血后逃跑并进入下一层。

UI 尺寸：

- 左上玩家 HUD：`min(174px, 45%) x 64px`，头像 `42 x 42`。
- 中央关卡框：宽 `min(148px, 34%)`，最小高 `64px`。
- 金币资源框：最小宽 `72px`，高 `29px`；移动端最小宽 `64px`，高 `28px`。
- 小地图：桌面 `120 x 88`，移动端 `104 x 78`，`aria-label="小地图"`。
- Toast：宽 `min(330px, 100% - 28px)`，顶部约 `164px`，层级 `z-index: 40`。
- 通用弹窗面板：宽 `min(100%, 390px)`，最大高 `100svh - 28px`，圆角 `8px`。
- 裂隙祝福三选一卡牌：容器最小高 `190px`；桌面卡牌宽 `31%`、最小高约 `132px`；移动端宽 `32%`、最小高约 `132px`。
