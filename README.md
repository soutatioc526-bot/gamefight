# 剑与魔法竞技场原型

一个零依赖 HTML5 原型，用来验证轻量土豆兄弟式的剑与魔法竞技场玩法。

## 运行

直接打开 `index.html`，或在目录里启动本地静态服务：

```powershell
python -m http.server 5173 --bind 0.0.0.0
```

同一 Wi-Fi 下手机访问：

```text
http://你的局域网IP:5173/
```

## 操作

- 手机：在屏幕任意位置按住并拖动，隐藏式摇杆会按拖动方向移动角色。
- 桌面：鼠标拖动，或使用 `WASD` / 方向键。
- 空格：标题页开始，战斗中打开或关闭设置。
- 右下齿轮：打开设置、天赋树、音量设置和保存进度。

## 当前循环

```text
自由移动
  -> 进入人物选择大厅
  -> 选择文帝 / 麦克 / 铭
  -> 四周限量刷怪并向玩家聚集
  -> 击杀直接获得经验，只掉落金币
  -> 升级三选一强化当前人物技能
  -> 升级获得技能点，可在人物天赋树里解锁职业玩法
  -> 每五层清完后进入金币商店
  -> 推进到第20层Boss
```

## 初始人物

- 文帝：近战冒险者，生命和防御较高，靠近怪物后自动挥剑。
- 麦克：远程冒险者，生命防御较低，自动发射奥术魔法飞弹。
- 铭：远程冒险者，生命防御较低，自动投掷远距离穿透飞镖。

## UI 与防误触

- 左上角显示头像、生命和经验，右上角显示金币/钻石，中间显示层数、倒计时和剩余怪物。
- 点击头像可以查看人物属性面板。
- 右下角齿轮打开设置菜单，可进入人物天赋、游戏音量设置、保存进度或返回游戏。
- 选择大厅、升级、商店窗口都有入场动画。
- 卡片和商店刚弹出时会锁定一小段时间，避免手机触摸残留导致误选。
- 升级卡以三张扑克牌展开，选择后燃烧消失并以附体光效进入角色。
- 标题、选择大厅、商店和升级窗口都会防误触。
- iOS 长按选中、全选菜单通过 CSS 和事件层禁止。
- 第 1 层开局怪物更少、更脆，攻击频率更慢，给玩家适应时间。

## 关卡结构

- 第 5 层：怪物头目。
- 第 10 层：精英怪。
- 第 15 层：副首领。
- 第 20 层：最终 Boss。
- 商店只在第 5 / 10 / 15 层清完后出现，第 20 层清完后通关。

## 性能与 Debug

- 敌人、掉落物、粒子、飘字、特效都使用对象池。
- 手机视口会降低敌人数上限。
- 每层有动态怪物生成预算，清完才进入下一层，避免无限刷怪导致卡顿。
- 敌人生命、防御、攻击、速度和数量会随层数曲线提高。
- 怪物使用 Canvas 变形轮廓动画，不再是静态图块。
- 粒子和飘字都有硬上限。
- 右侧 debug 面板默认关闭，URL 加 `?debug=1` 时才保留数据入口。

## 音效

音效使用 Web Audio API 合成，无外部音频文件：

- 近战：短促挥砍。
- 文帝：短促挥砍和低频剑势。
- 麦克：高频奥术魔法飞弹。
- 铭：弓弦拨动感的飞镖投掷。
- 卡片：发牌、燃烧、附体分别有不同反馈。
- 页面切换、息屏恢复后会尝试恢复 Web Audio 上下文；再次触摸屏幕也会重新解锁音频。
- 商店购买确认有独立金币确认音效。
- 游戏音效和背景音效都能在设置里调节或关闭。

## 调试键

URL 加上 `?debug=1` 后可用：

- `N`：强制清层。
- `6`：跳到第 5 层并触发商店。
- `8`：生成当前层特殊怪。
- `9`：生成最终 Boss。
- `0`：直接获得一次升级所需经验。
