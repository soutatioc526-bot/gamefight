# Gamefight 割草肉鸽 Demo

一个零依赖 HTML5 Canvas 原型，方向调整为碎片时间可反复打开玩的肉鸽割草循环。

## 运行

直接打开 `index.html`，或在项目目录启动本地静态服务：

```powershell
python -m http.server 5173 --bind 0.0.0.0
```

本机访问：

```text
http://127.0.0.1:5173/
```

## 当前玩法

- 主界面只保留“开始冒险”。
- 如果有上一次选择的初始武器，会直接进入战斗。
- 如果没有记录，会进入初始武器选择。
- 当前版本只有一个统一主角，三张开局卡是初始武器，不是角色。
- 战斗中升级奖励和层间奖励分离。
- 祝福只来自神龛、Boss、精英或特殊层间奖励，不进入商店。
- 普通局以第 9 层为完整小循环，第 10-20 层是继续深入挑战。

## 初始武器

- `Knife`：近战收割，短冷却扇形刀光。
- `MagicMissile`：远程追踪，稳定单体输出。
- `Dart`：回旋轨迹，飞出和返回都能造成伤害。

## 操作

- 移动端：按住屏幕任意位置拖动，会在触点位置显示低透明虚拟摇杆。
- 桌面端：`WASD` 或方向键移动。
- 武器自动攻击，不需要手动点怪。
- 空格：标题页开始冒险，战斗中打开/关闭暂停菜单。

## 当前循环

```text
开始冒险
  -> 自动使用上次武器或选择初始武器
  -> 进入战斗
  -> 击败敌人获得经验和金币
  -> 战斗升级三选一，可用金币刷新
  -> 每层结束进入层间房间
  -> 每 3 层阶段结算
  -> 第 9 层完成普通局，可选择继续深入
  -> 死亡后可立即再来一局
```

## 存档字段

使用 `localStorage` 保存轻量长期记录：

- `lastStartingWeapon`
- `unlockedAchievements`
- `highestFloor`
- `clearedNormalMode`
- `unlockedDeepChallenge`
- `highestKills`
- `bestSynergy`
- 设置项预留
